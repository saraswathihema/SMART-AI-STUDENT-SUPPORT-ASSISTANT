# Smart AI Student Support Assistant

An AI-powered web application developed for PET Engineering College to help students get quick answers to college-related queries.

## Features

- Course information
- Admission process
- Eligibility details
- Academic information
- College facilities
- Document-based question answering
- Simple and user-friendly interface

## Technologies Used

- Python
- Streamlit
- LangChain
- HTML/CSS
- PDF Documents

## How to Run

Install the required packages:

pip install -r requirements.txt

Run the application:

streamlit run app.py

## Project Objective

The main objective of this project is to provide students with quick and easy access to college-related information using Artificial Intelligence.
